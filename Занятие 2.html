АЛГОРИТМЫ ЕСТЬ В ПОВСЕДНЕВНОЙ ЖИЗНИ03
03 · Понятие

Что такое алгоритм?

Алгоритм — это конечная, понятная и упорядоченная последовательность действий, предназначенная для решения задачи или получения результата.

Последовательность

Действия расположены в определённом порядке.

Понятность

Каждый шаг должен быть однозначно понятен исполнителю.

Конечность

Алгоритм должен завершаться за конечное число шагов.

Результативность

Выполнение должно приводить к ожидаемому результату.

АЛГОРИТМИЧЕСКОЕ МЫШЛЕНИЕ ПРЕДШЕСТВУЕТ КОДУ05
05 · Свойства

Основные свойства алгоритма

Дискретность

Алгоритм состоит из отдельных шагов.

Определённость

Каждый шаг не должен допускать противоречивого толкования.

Конечность

Количество шагов не бесконечно.

Результативность

После выполнения получается результат.

Массовость

Алгоритм часто применим к целому классу похожих задач.

Исполнимость

Каждое действие должно быть выполнимо выбранным исполнителем.

06 · Исполнитель

Кто может выполнять алгоритм?

Исполнитель — тот, кто способен понять команды алгоритма и выполнить их.

👤 Человек

Следует инструкции, например инструкции по сборке мебели.

🤖 Робот

Выполняет команды управления движением и действиями.

💻 Компьютер

Выполняет команды программы в соответствии с правилами языка.

Важно: команда «сделай красиво» может быть понятна человеку в контексте, но плохо подходит для автоматического исполнителя.

08 · Реальный пример

Алгоритм приготовления чая

Взять чашку
→
Положить чай
→
Нагреть воду
→
Залить водой
→
Подождать

Но можно сделать алгоритм точнее

  1. Налить воду в чайник.
  2. Включить чайник.
  3. Дождаться нагрева воды.
  4. Положить пакетик чая в чашку.
  5. Налить горячую воду.
  6. Подождать 3–5 минут.

Чем точнее инструкции, тем меньше вероятность неправильного результата.

БЛОК-СХЕМА ПОМОГАЕТ «УВИДЕТЬ» АЛГОРИТМ11
11 · Тип 1

Линейный алгоритм

Линейный алгоритм — алгоритм, в котором команды выполняются последовательно, одна за другой, без выбора и повторения.

Начало
→
Действие 1
→
Действие 2
→
Действие 3
→
Конец

Пример

Найти площадь прямоугольника:

Ввести a Ввести b S = a * b Вывести S

Главный признак

Нет вопросов вида «если… то…» и нет повторения одного и того же блока.

Шаг 2

Получаем ширину.

Шаг 3

Шаг 4

Выводим результат.

Разветвлённый алгоритм

Разветвлённый алгоритм содержит условие. В зависимости от результата проверки выбирается один из вариантов действий.

Начало
→
Проверка условия?

Да / True

Условие истинно → выполняется ветвь A.

Нет / False

Условие ложно → выполняется ветвь B.

if температура > 20:   взять лёгкую одежду else:   взять тёплую одежду
ТИП 2 · ВЫБОР14
14 · Тип 2

Примеры разветвления

🌧 Погода

Если идёт дождь → взять зонт. Иначе → идти без зонта.

🔐 Пароль

Если пароль верный → доступ разрешён. Иначе → отказ.

🎓 Оценка

Если балл ≥ порога → зачёт. Иначе → нужна доработка.

🛒 Покупка

Если товара достаточно → оформить. Иначе → сообщить о нехватке.

🚦 Переход

Если зелёный → можно переходить. Иначе → ждать.

🌡 Температура

Если холодно → надеть куртку. Иначе → выбрать лёгкую одежду.

УСЛОВИЯ ПОЗВОЛЯЮТ ПРОГРАММЕ «ПРИНИМАТЬ РЕШЕНИЯ»16
16 · Тип 3

Циклический алгоритм

Циклический алгоритм содержит повторение действий. Один и тот же набор команд выполняется несколько раз.

Начало
→
Условие
→
Действия
↺

Пример из жизни

Пока посуда не закончилась → взять следующую тарелку → помыть → повторить.

Пример в программе

Вывести числа от 1 до 10, не записывая команду print() десять раз.

ТИП 3 · ПОВТОРЕНИЕ17
17 · Тип 3

Циклы в Python

for i in range(1, 6): print(i)

Что произойдёт?

Команда print(i) выполнится для значений 1, 2, 3, 4 и 5.

Зачем цикл?

Чтобы не дублировать одинаковый код и удобно работать с повторяющимися действиями.

Другой вариант

count = 0 while count < 5: print(count) count = count + 1
