ОТ АЛГОРИТМА К ПРОГРАММЕ02
02 · Понятие

Что такое алгоритм?

Алгоритм — это конечная, понятная и упорядоченная последовательность действий, которая приводит к решению задачи или получению результата.

Просто

Алгоритм отвечает на вопрос: «Что и в каком порядке нужно сделать?»

В программировании

Алгоритм описывает логику решения, а программа записывает эту логику на языке программирования.

АЛГОРИТМ = ПЛАН ДЕЙСТВИЙ ДЛЯ ПОЛУЧЕНИЯ РЕЗУЛЬТАТА03

04 · Пример

Алгоритм приготовления чая

1Налить воду
2Нагреть воду
3Положить чай
4Залить водой
5Подождать

Почему это алгоритм?

  • действия расположены в определённом порядке;
  • каждый шаг понятен исполнителю;
  • есть конечный результат;
  • если нарушить порядок, результат может измениться.
ПЕРВЫЙ ПРИМЕР — ПОСЛЕДОВАТЕЛЬНОСТЬ ДЕЙСТВИЙ05
05 · Свойства

Каким должен быть алгоритм?

Определённость

Каждый шаг должен быть однозначно понятен.

Дискретность

Алгоритм состоит из отдельных шагов или команд.

Конечность

Для конкретной задачи алгоритм должен завершаться.

Результативность

Выполнение должно приводить к ожидаемому результату.

Массовость

Алгоритм может применяться к целому классу похожих задач.

Понятность

Исполнитель должен понимать предусмотренные действия.

11 · Условие

Пример из жизни: переход дороги

Алгоритм

  1. Подойти к переходу.
  2. Проверить сигнал светофора.
  3. Если разрешающий сигнал — перейти по правилам.
  4. Иначе — дождаться разрешающего сигнала.

Логика

если сигнал разрешает: перейти иначе: ждать

Это уже не просто последовательность: появился выбор.

КОМПЬЮТЕРЫ ОСОБЕННО СИЛЬНЫ В ПОВТОРЯЮЩИХСЯ ОПЕРАЦИЯХ15
15 · Python

Цикл for в Python

for i in range(5): print("Привет!")

Что произойдёт?

Команда print() будет выполнена 5 раз.

В циклах важно понимать две вещи: что повторяется и сколько / до какого условия повторяется.

Без цикла

print("Привет!") print("Привет!") print("Привет!") ...

С циклом

for i in range(5): print("Привет!")

Определи тип алгоритма

Ситуация A

Ввести длину и ширину → вычислить площадь → вывести результат.

Какой тип?

Ситуация B

Если температура ниже 0 — вывести «мороз», иначе — «не мороз».

Какой тип?

Ситуация C

Вывести на экран числа от 1 до 100.

Какой тип?

Ситуация D

Проверить каждый товар в списке и выбрать товары с нужным условием.

Какой тип или комбинация?

Ответ: A — линейный; B — разветвлённый; C — циклический; D — цикл + разветвление.
